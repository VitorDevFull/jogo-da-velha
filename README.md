# Jogo da Velha

Projeto simples de Jogo da Velha desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Dois jogadores: X e O
- Verificação de vencedor
- Verificação de empate
- Placar de vitórias e empates
- Botão para nova rodada
- Botão para resetar o placar
- Layout responsivo para celular e computador

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo do projeto

Este projeto foi criado para praticar conceitos básicos de JavaScript, como manipulação do DOM, eventos de clique, arrays, funções e estruturas condicionais.
